# Kawá ESDD Site Visit App

Static GitHub Pages app for Kawá ESDD fieldwork.

## Files
- `index.html` – main page
- `styles.css` – mobile-friendly styling
- `app.js` – save/export/import logic
- `data.js` – embedded form questions
- `data.json` – editable source data backup

## Publish on GitHub Pages
1. Create a repo, e.g. `KawaDD`.
2. Upload all files in this folder to the root of the repo.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Branch: **main**. Folder: **/root**.
6. Save and open the GitHub Pages link.

## Field use
- Open the GitHub Pages link on the phone.
- Press **Save Response** after each interview.
- Export **CSV** or **JSON** at the end of each day.
- On iPhone, use Safari and then **Share → Add to Home Screen**.

Data is stored locally in the browser. Export regularly as backup.
